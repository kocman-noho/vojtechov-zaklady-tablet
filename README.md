# Vojtěchov — wind turbine foundation study

> **Tablet version** — Czech full-canvas interface with floating control bars, tuned for iPad and other tablets. Live: https://kocman-noho.github.io/vojtechov-zaklady-tablet/ · Desktop original: https://github.com/kocman-noho/vojtechov-zaklady

[**Beneath: interactive 3D experience**](experience/README.md) combines the detailed foundation, a trimmed and fitted version of the supplied turbine, animated deconstruction, and everyday scale comparisons.

```sh
cd experience
npm ci
npm run dev
```

Open http://localhost:5173. Production files are built with `npm run build`.

The original [CAD and printable models](models/README.md), their existing [offline review page](models/output/preview.html), supplied drawings and original turbine assets are preserved. Browser derivatives and their processing notes are in `experience/public/models/`.
